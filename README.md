## The entry

A phone at one percent battery sends its final text — a last confession of
everything it witnessed before it goes dark for good.

## How it works

`main.ts` writes the one-liner (under 200 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, deterministically, with no network and no
input beyond the text itself.

## Run

```sh
node main.ts
```
